React Lab Exercise 3: State in React 
Topic: State using useState() 
1. Aim 
To create a simple React application that demonstrates the use of State using the useState() Hook. 
 
2. Objectives 
After completing this experiment, students will be able to: 
• Understand the concept of State in React. 
• Create state using useState(). 
• Update state using a state setter function. 
• Handle button click events. 
• Understand how changing state updates the UI. 
 
3. What is State? 
State is data that can change during the execution of a React application. 
Examples 
Counter value 
Student name 
Selected option 
Login status 
Button status 
Form data 
Simple idea 
State 
  ↓ 
Value changes 
  ↓ 
React detects the change 
  ↓ 
Component re-renders 
  ↓ 
Updated UI

12. Step 8: Complete App.jsx 
Your complete program is: 
import { useState } from "react"; 
 
function App() { 
 
  const [count, setCount] = useState(0); 
 
  return ( 
    <div> 
      <h1>React State Example</h1> 
 
      <h2>Count: {count}</h2> 
 
      <button onClick={() => setCount(count + 1)}> 
        Increase 
      </button> 
 
      <button onClick={() => setCount(count - 1)}> 
        Decrease 
      </button> 
    </div> 
  ); 
} 
 
export default App;

14. How Does State Work? 
Suppose the initial state is: 
useState(0) 
Initial 
count = 0 
User clicks Increase: 
setCount(count + 1) 
React changes the state: 
count = 1 
React then re-renders the component. 
Button Click 
     ↓ 
setCount() 
     ↓ 
State changes 
     ↓ 
React re-renders 
     ↓ 
Updated value displayed 
 
15. Important Concept 
Do NOT do this: 
count = count + 1; 
Instead, use: 
setCount(count + 1); 

The setter function tells React that the state needs to be updated.

18. Complete Example with Two States 
import { useState } from "react"; 
 
function App() { 
 
  const [count, setCount] = useState(0); 
  const [name, setName] = useState("Rahul"); 

 
  return ( 
    <div> 
 
      <h1>React State Example</h1> 
 
      <h2>Student Name: {name}</h2> 
 
      <button onClick={() => setName("Priya")}> 
        Change Name 
      </button> 
 
      <hr /> 
 
      <h2>Count: {count}</h2> 
 
      <button onClick={() => setCount(count + 1)}> 
        Increase 
      </button> 
 
      <button onClick={() => setCount(count - 1)}> 
        Decrease 
      </button> 
 
    </div> 
  ); 
} 
 
export default App;

22. Common Beginner Mistakes 
Mistake 1 
const count = 0; 
This is just a normal JavaScript variable, not React state. 
Use: 
const [count, setCount] = useState(0); 
Mistake 2 
count++; 
Do not directly modify React state. 
Use: 
setCount(count + 1); 
Mistake 3 
Forgetting to import: 
import { useState } from "react"; 
 
23. Viva Questions 
1. What is State? 
State is data that can change during the execution of a React component. 
2. Which Hook is used to create state? 
useState(). 
3. What is the initial value in useState(0)? 
0. 
4. What is setCount? 
It is the state setter function used to update count. 
5. Can we directly modify state? 
No. We should use the setter function. 
6. What happens when state changes? 
React re-renders the component and updates the UI. 

7. Can a component have multiple state variables? 
Yes.
